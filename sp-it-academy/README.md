# SP IT Academy Website

Production-oriented static website starter using HTML, CSS and vanilla JavaScript.

## Run locally
Open `index.html` directly, or use VS Code Live Server.

## Deploy
Push this folder to GitHub and deploy with Cloudflare Pages, Netlify or Vercel as a static site.

## Before launch
- Replace placeholder logo, student, campus and course assets.
- Replace placeholder copy and statistics with verified company information.
- Update `robots.txt` and `sitemap.xml` with the real domain.
- Add your actual contact/form backend.
- Add canonical URLs and page-specific SEO metadata.
- Test mobile, tablet, accessibility and performance.
